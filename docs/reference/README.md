# Design references (not shipped code)

These two standalone HTML mock-ups were part of the original client hand-over. They are kept as
design references only: nothing in `src/` imports them, they are not served by the app, and they are
**not** a specification — `docs/PRD.md` and `docs/ui-ux.md` are the contract, and the running app is
the truth.

| File | What it shows |
| --- | --- |
| `ghs_learnportal.html` | Early visual exploration of the learner dashboard and library |
| `ghana_health_service_cpd_clinical_learning_portal_ghs_cpd.html` | Early visual exploration of the marketing page and programme taxonomy |

They live here, outside `docs/`, so a reader does not mistake them for documentation of the current
build. If a future design needs them, copy the relevant ideas into `docs/ui-ux.md` rather than
linking the HTML.

**Provenance.** Created for this project during the GHS-TL discovery phase; no third-party
templates or fonts are embedded (system font stack only). The GHS wordmark and flag colours are
public-service identity marks and should be reproduced per Ghana Health Service brand guidance.
